🚀 QUICK START GUIDE:

1. INSTALL EVERYTHING (in your actual WSL):
   bash wsl-setup.sh

2. VERIFY INSTALLATION:
   bash check-setup.sh

3. START NEOVIM:
   nvim
   (Wait for plugins to install on first launch)

4. START TMUX:
   tmux
   (Press Ctrl+Space then I to install plugins)

5. EXPLORE:
   - Open README.md for detailed guide
   - Check CHEATSHEET.txt for quick reference
   - Press Space in Neovim to see all commands!

🎯 KEY FEATURES:

✨ NEOVIM:
   • Auto-completion as you type
   • FREE AI code suggestions (Codeium)
   • File explorer with icons (Space + e)
   • Fuzzy find files (Space + ff)
   • Fuzzy find text (Space + fg)
   • Go to definition (gd)
   • Show documentation (K)
   • Command helper (press Space)

✨ TMUX:
   • Split panes (Prefix + | or -)
   • Multiple windows (Prefix + c)
   • Session management
   • Auto-save sessions

✨ BASH:
   • Fuzzy command history (Ctrl + r)
   • Fuzzy file finder (Ctrl + t)
   • Smart cd with zoxide (z dirname)
   • Beautiful ls with eza (ll, la, lt)
   • Git shortcuts (gs, ga, gc, etc)

💡 PRO TIPS:

1. Use tmux sessions for different projects
2. Press Space in Neovim to discover commands
3. Use Ctrl+r for fuzzy command history
4. Use 'z' to jump to frequently used directories
5. The AI completion (Codeium) is FREE and works great!

📍 FILE LOCATIONS:

All your configs are in ~/.config/:
• ~/.config/nvim/     - Neovim configuration
• ~/.config/tmux/     - tmux configuration
• ~/.bashrc           - Bash configuration
• ~/.gitconfig        - Git configuration

🎨 CUSTOMIZATION:
